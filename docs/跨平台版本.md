# macOS / Linux 跨平台版 1.3.0

此目录的发行包是独立的 Electron 桌面程序，Windows 1.2.1 原生版继续保留。

## 下载选择

| 文件名包含 | 适用电脑 |
| --- | --- |
| `mac-arm64` | Apple Silicon Mac，M1 / M2 / M3 等 |
| `mac-x64` | Intel Mac |
| `linux-x64` | Intel / AMD 64 位 Linux |
| `linux-arm64` | ARM64 Linux |

macOS 要求 12 或更新系统。Linux 建议 Ubuntu 22.04 / Debian 12 或更新桌面系统，需系统提供 GTK3、NSS、ALSA、GBM、ATK 等 Electron 桌面依赖。ARM64 必须使用 64 位系统。

## 使用

- macOS：打开 `.dmg`，将 `YukkuriVoice.app` 拖到“Applications”；也可解压 ZIP，将应用移到“应用程序”。
- Ubuntu / Debian：使用系统软件安装工具打开对应架构的 `.deb`。其他发行版可使用便携 `.tar.gz`。
- Linux：解压 `.tar.gz`，运行目录内的 `yukkuri-voice` 或 `启动油库里语音.sh`。
- 发行包自带 Electron、离线合成所需运行资源，无需 .NET、Node.js、Wine 或在线合成服务。
- 从音色下拉框选择基础音色，调整语速，在工作台或悬浮窗输入文字，生成、试听或导出 WAV。
- 八种基础 AT1 音色通过 WebAssembly x86 模拟器运行原始声库；不修改声库文件。许可证随声库保存。
- 可以导入合法持有、适用于当前系统和 CPU 的 AquesTalk 本机引擎；Windows DLL 不能作为 macOS/Linux 本机引擎加载。AT2 需要完整 phont 目录，AT10 提供七个预设。官网下载的评估 SDK 不包含在发行包中。

## QQ 功能状态

QQ 集成标记为实验性，按本次需求未进行 macOS/Linux QQ 连接或发送实机测试。

- 不移植 Windows 进程注入器；跨平台连接尝试使用 QQ 的本机调试通道，服务只绑定 `127.0.0.1`。
- 需要退出已经运行的 QQ，然后从设置页“启动 QQ”。登录并打开目标会话后点击“刷新会话”，只有确认连接后才启用发送按钮。
- 如果 QQ 版本不接受本机调试参数、未暴露兼容 IPC 或当前会话无法识别，连接/发送会失败；不承诺目前可在所有 QQ 版本发送。
- 不扫描联系人和聊天数据库；发送前再次核对会话，超时不会自动重发。
- 当前跨平台版不包含 Windows 的自动读取 QQ 草稿和全局取词热键。在工作台/悬浮窗编辑文字，或粘贴需要合成的文字。

## 验证范围

已在 Windows 开发主机运行跨平台 Electron 程序，验证八种基础音色实际合成、语速、WAV 格式、原始 DLL/许可证完整性、界面布局、波形、悬浮窗文字同步和历史记录。

macOS / Linux 发行包通过官方 Electron 目标运行时打包，校验原始运行时下载摘要及包内容。仓库的 `Build macOS and Linux packages` 工作流在 Intel Mac、Apple Silicon Mac、Linux x64、Linux ARM64 四种构建机上执行离线合成、打包和已打包应用的基础界面检查；逐包 JSON 的 `targetRuntimeTested` 仅在该次检查成功后设为 true。该检查不会启动或连接 QQ。

macOS 原生构建包使用本地 ad-hoc 签名，并验证签名及磁盘镜像完整性；尚未使用 Apple Developer ID 证书，也未公证。公众发行仍可能遇到 macOS 来源验证提示；完善认证需维护者的 Apple 开发者账号。程序不会更改系统安全设置。Linux 不要求以 root 运行，`.deb` 会安装正确权限的 Chromium 沙箱辅助程序；便携包要求系统支持普通用户的 Chromium 沙箱。

## 源码

```text
cd src/Yukkuri.CrossPlatform
npm ci
npm test
npm run test:ui
npm start
```

目标平台打包脚本见 `scripts/package.cjs`。下载时需要访问 Electron 官方发行资源；构建所用版本和依赖通过 package-lock 固定。macOS `.dmg` 和 ad-hoc 签名由 Mac 构建机生成；Windows 可以生成未签名的目标 ZIP 和 Linux 包。CI 构建产物暂存 14 天，正式发行应将产物作为 Release 附件发布。
