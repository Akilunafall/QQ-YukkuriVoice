# 1.2.1 验证记录

验证日期：2026-11-15。环境：Windows 11 x64，.NET 10。

## 已验证

- Release 构建零警告、零错误。
- 完整本机 smoke 共 341 项通过，结果：`.test-data/test-results.json`。
- 实际生成 30 个音色：旧许可 AT1 八个、官方评估 AT1-F3、AT2 十四个、AT10 七个。
- 每个保存 WAV 与对应 DLL 原始输出逐字节相同；无额外量化、调制、移调、音量修改。记录原始采样率、时长、峰值、RMS 和 SHA-256。
- 语速 0.65× / 1.60× 在三代引擎内部改变时长；独立 x86 进程实际调用 AT1/2/10 对应 ABI。
- AT2 共享 DLL 的 phont 切换、AT10 共享 DLL 的七种参数预设切换、选择保存/恢复通过。
- 旧设置的机械感、音高与音量参数迁移为原声默认值。
- 取消、240 字符限制、本地历史、文件删除路径边界、QQ 草稿候选筛选通过。
- 25 项本地 QQ JavaScript 传输测试通过，覆盖精确窗口句柄和会话、PTT 元素、消息编号和音频校验值确认、切换/歧义取消、拒绝/超时不重试、本机密钥校验。新增真实接口要求的 Map/undefined 类型、PTT 业务字段、原生 Error 细节、编码后完整提交链、同请求不重复发送，以及临时抓包入口已移除的检查。这组测试本身只使用隔离的模拟 IPC。
- WPF 真实控件离屏渲染 1000×700 / 1200×820 工作台、设置页及悬浮窗，PNG 在 `.test-data/screenshots`，已检查文字及按钮布局。此项不是桌面点击验收。
- 自建本地 x64 注入模块已实际连接正在运行的 QQ 9.9.29-47354，无注册、在线授权或 QQ 安装文件修改。只在 QQ 主进程 JavaScript 线程执行本软件的固定桥接。
- 已从 QQ 的当前会话状态读取真实好友/群标识；未扫描聊天数据库、没有导出联系人或历史消息。
- 已在实际 QQ 渲染进程调用消息编号生成接口及真实语音发送接口，均收到匹配回调；真实发送结果见下节。
- 30 个音色的发送副本在本地转换为 24 kHz 单声道 PCM，原始 WAV 保持不变；随后在运行中的 QQ 进程内实际编码为有效 SILK，结果：`.test-data/local-qq-audio-results.json`。不再依赖外部 FFmpeg 或 Node 运行时。
- 悬浮窗编辑框的多行输入、240 字限制、工作台双向同步、编辑后旧音频失效均已通过 WPF 控件测试。离屏截图检查了编辑框、会话文字和按钮布局。
- 注册令牌、网站跳转、手动联系人下拉框和旧 OneBot 启动流程已从当前版本移除；保存设置不再包含服务令牌。

## 真实发送验收

- 用户明确授权在指定测试群内调试。所有本次真实测试消息都只发送至该群；目标同时校验聊天类型、真实 UID 和群名。公开记录不包含群标识和消息编号。
- 初始真实发送被 QQ 拒绝，原因为 `Cannot convert undefined or null to object`。隔离模拟 IPC 未覆盖原生类型和必需业务字段，因而此前通过不能证明真实发送成功。
- 被动核对该群原生文字发送请求发现，`msgAttributeInfos` 是 Map，第二个可选参数为 undefined；JSON 会分别显示为普通空对象和 null，旧代码丢失了这两个类型。捕获监听器已精确移除，正式版本无捕获命令。
- PTT 补全 `voiceType: 1`、`autoConvertText: 0`、`storeID: 0`、`otherBusinessInfo: { aiVoiceType: 0 }` 后，本地发送测试获得有效消息编号，QQ 实际出现新的 4 秒语音气泡。点击后播放图标切换至暂停状态，未出现错误提示。
- 实际运行便携版 1.2.1，点击主窗口“一键发送 QQ 语音”，完成合成和发送，界面显示成功及对应消息编号，QQ 实际新增对应语音气泡。
- 在相同 MiniWindow 控件中将文字改为“悬浮窗发送测试，今天也要慢慢来。”，点击发送，界面显示“QQ 已接受语音消息”，QQ 再次新增 4 秒语音气泡。此项通过开发入口显示相同控件、数据绑定和发送处理器；仅为桌面工具的窗口发现将边框临时设为普通窗口，正式版悬浮窗样式未改。
- 共实际确认三条原生语音；用于核对参数的文字测试消息也只发在上述授权群聊。

## 尚未覆盖

- 未从其他群成员的设备核验接收或播放；界面的播放状态验证也不等于主观听感验收。
- 非官方集成可能触发客户端安全检查或账号限制。QQ 更新、重新登录、多账号、多独立聊天窗的长期稳定性未全面验证。
- 官网评估 SDK 有「ナ行、マ行→ヌ」限制。程序保留该限制，未尝试破解、移除或绕过。
- 未对 Yukumo 网站与本机输出做同文本、同正式音色版本的主观试听/频谱对照；不宣称完全一致。
