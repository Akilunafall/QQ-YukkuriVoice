目标系统界面检查运行真正的打包程序，不使用模拟语音引擎；检查实际合成、八种音色列表、语音波形像素、宽屏/窄窗口布局、悬浮窗编辑与主窗口同步、历史记录和本机引擎加载器模块。Linux 检查在 Xvfb 桌面中运行；没有进行主观音质或扬声器试听验收。

Mac 使用 ad-hoc 签名，并以 `codesign --verify --deep --strict` 验证。DMG 通过 `hdiutil verify`。这不是 Apple Developer ID 签名或 Apple 公证。

Linux DEB 包包含桌面启动项、图标和系统依赖声明，Chromium 沙箱辅助程序以 root 所有、4755 权限装入系统包。DEB 的安装/卸载本身未做完整用户桌面流程验收。

## 音频一致性

- 八种基础音色的原始 DLL 和 AqLicence.txt 与 Windows 版本逐字节一致。
- 每种打包音色 ZIP 内同时包含原始许可证文件，DLL 未修改或改名。
- 在开发主机用相同文字与语速，跨平台八种基础音色输出 WAV 与 Windows 原生合成的八个对照文件逐字节一致。
- 在各平台实际合成快慢语速，验证有效 16 位单声道 PCM、非零音频峰值、合理时长变化。
- 中文转假名、非法输入及参数错误、QQ 音频副本格式转换均有本地测试。

## 明确未测试

- 按用户本次要求，不启动、不连接 QQ，也不发送 QQ 测试消息。
- macOS / Linux 的 QQ 模块为实验性，不将四平台界面/合成检查当作 QQ 可用证明。
- 自动读取 QQ 草稿、Windows 内存注入器和全局取词热键没有移植到该版。
- 第三方授权本机引擎的导入需要匹配当前系统与 CPU，完整 AT2/10 SDK 不随包提供；未承诺所有 SDK 版本已实机验收。
- 未做 Apple 公证、多种 Linux 发行版、多显示器、屏幕阅读器及长期压力验收。
